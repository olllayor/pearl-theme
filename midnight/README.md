# Midnight Dark Theme for Zed

> *Midnight — Nord-inspired dark blue for focused night coding.*

A dark color theme crafted for [Zed](https://zed.dev).

## Variants

- **Midnight Dark**: A Nord-inspired midnight blue dark theme for focused night coding.

## Installation

1. Open Zed.
2. Open the Extensions view (`cmd-shift-x` on macOS or `ctrl-shift-x` on Linux/Windows).
3. Search for **Midnight Dark**.
4. Click **Install**.
5. Open the theme selector (`cmd-k cmd-t`) and select **Midnight Dark**.
